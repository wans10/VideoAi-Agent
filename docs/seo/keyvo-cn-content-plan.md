## 1. 现状一句话

首页和 17 个模型页、5 个案例分类页已经有可抓取的服务端渲染内容，但多为上游翻译来的通用说明，缺少"Keyvo 自己的原创中文使用经验"。百度是否把这些页面当作有价值内容，**未验证**；通用做法是原创、有信息增量的页面更容易被收录和留存。

## 3. 模型页与案例页"不单薄"的最低要求

每个对外开放的模型页（17 个）和每个案例分类页（5 个）应包含，且是原创中文，不是机翻上游：

1. **一句话定位**：这个模型擅长什么、不擅长什么（基于 Keyvo 实测，不抄厂商宣传）。
2. **适用场景**：3~5 个具体场景（电商短视频、角色连续、口播、产品展示……），每个附一个真实生成案例（来自 Keyvo 案例库，可复刻）。
3. **提示词示例**：2~3 条可直接复制的中文提示词，标注对应参数；说明写法规律（主体、运镜、环境、节奏）。
4. **注意事项**：时长/分辨率/参考素材限制、容易失败的写法、内容安全规则；与同厂商相邻版本的取舍（如 Kling 3 Standard 与 Pro）。
5. **价格说明**：读取 Keyvo 自己的人民币报价（页面组件已有实时报价，不手写数字），并说明"生成前显示价格、失败退款"的规则；文字内容不得出现与实时价格不一致的数字。
6. **常见问题**：只写页面上可见的问答，对应 FAQPage 结构化数据；不要出现未上架模型。
7. **正文规模**：建议至少 600~800 个汉字的原创说明（经验值，**未验证**百度的"薄内容"阈值）。
8. 页面里的 "VideoAI"、美元价格、未上架模型名一律清除（品牌字样已在元数据层统一替换，正文建议同步清理源内容）。

## 4. 内部链接计划

- 首页 → 价格页、模型目录、案例页、提示词助手（已有，确认锚文字带关键词，如"AI 视频价格""文生视频案例"）。
- 模型目录 `/zh/models` → 每个模型页（锚文字用"可灵 Kling 4.0""Wan 3"等中英文名）。
- 模型页 ↔ 对应案例分类页（双向）；模型页 → 价格页；案例页 → 模型页。
- 新建的教程页（文生视频、图生视频、提示词）→ 相关模型页与案例；模型页底部"相关教程"回链。
- 每个页面保证至少 3 个站内入链；孤立页面不进 sitemap。
- 面包屑：模型页目前没有 BreadcrumbList，建议补（`首页 > 模型 > Kling 4.0`），需与可见面包屑一致。

## 6. 站外动作（对品牌词有帮助，但**不保证排名**）

以下对搜索结果的实际影响程度均**未验证**，是行业常见做法：

| 渠道 | 做什么 | 注意 |
|---|---|---|
| 百度百科 | 词条要求是被权威/第三方独立来源报道过的、有知名度的主体；刚上线的新品牌通常过不了审核，**不要花钱找人"代做"** | 达不到条件就先积累媒体报道/行业榜单 |
| 企业认证 | 百度站长平台/百度爱采购/微信公众号认证、天眼查类企业信息页，让"Keyvo + 公司主体"信息一致 | 主体名称与站点"运营者信息"页保持一致 |
| 知乎 | 以真实使用者身份写"如何用 AI 做视频"类回答/文章，附 Keyvo 链接；知乎在百度的权重较高（**未验证**当前强度） | 不要刷赞/小号，被发现会适得其反 |
| 小红书 | 发真实生成案例和提示词，引导搜索"Keyvo" | 注意平台对 AI 生成内容的标注要求 |
| B站 | 发教程/评测视频，简介放官网 | 视频须是原创 |
| 微信公众号 | 注册公众号并发布教程，文章在微信搜一搜和百度都有曝光机会（**未验证**） | 与站点 about 页主体一致 |
| 友情/行业导航 | 提交到靠谱的 AI 工具导航站 | 避开买链接和垃圾外链站 |

诚实边界：这些动作只能增加"有人提到 Keyvo"的机会。能否让 Keyvo 一词排在第一，取决于是否有重名竞争、站点是否被收录以及内容质量。
