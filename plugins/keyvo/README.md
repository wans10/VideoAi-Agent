# Keyvo 独立候选插件

Keyvo 为 AI 视频和图像提供模型规划、准确报价、明确批准后的生成和任务恢复。需要 Keyvo 账户，通过 OAuth 登录；不要在插件中填入供应商密钥。

本包版本为 0.1.0，尚未发布到市场，尚未在客户端安装验收。安装包静态检查不能证明主机连接或生成已通过。

- `plan`：模型与预算规划。
- `generate`：精确报价、批准后的单次生成、结果获取和恢复。
- MCP 地址：`https://app.keyvo.cn/mcp`。
- `maxvideoai` 插件 ID 与 MCP 依赖 ID 为兼容标识；显示名称和连接目标为 Keyvo。

参阅 [连接与验收边界](docs/connection.md)。客户安装源应使用经过 CI 验证的固定 Git 标签；本候选版本没有已发布标签，不提供虚构安装命令。当前不启用生产 MP4 导出。
