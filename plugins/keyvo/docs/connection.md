# 连接与验收边界

候选 MCP 资源为 `https://app.keyvo.cn/mcp`。OAuth protected-resource 元数据应声明同一资源，认证服务器应使用 Keyvo 已配置的 Supabase Auth。连接、认证、工具发现和实际执行应分别验收。

本轮只验收安装包，不安装 Claude、Codex 或其他客户端，不宣称主机选择能力已验证。发布前须另行记录主机版本、安装、认证、重连与实际工具调用证据。

每次生成必须获得准确报价及明确批准。响应不确定时恢复原任务，不创建新任务规避恢复流程。模型和价格以实时工具结果为准。导出功能取决于服务端独立开关；当前生产导出关闭。

本地文件须通过授权导入取得归属资产，再作为生成参考。辅助脚本用 `node scripts/import-reference-files.mjs --help` 查看用法，不把密钥写进安装包。
